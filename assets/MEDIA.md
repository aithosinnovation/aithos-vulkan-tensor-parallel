# Figures and media

Figures are rendered from stored benchmark measurements. The comparison chart shows every timing and process-median range for prompt processing and token generation at explicitly labelled batch settings. Other figures show numerical-error rows, observed memory peaks, a conceptual topology, and workload-specific measurements.

The animated figure deck presents three stored measurement figures. It is not a screen recording or a real-time inference demonstration. No timing values are simulated or interpolated. PNG metadata contains only the lab software label and DPI; no personal or location metadata is included.
