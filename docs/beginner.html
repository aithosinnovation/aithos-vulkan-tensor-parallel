Two GPUs.
One model.
Worth it?

We asked whether an Intel Arc Pro B70 and an NVIDIA RTX 3090 work better together when running a language model.

THE SHORT ANSWER

They worked together. The RTX alone was faster in this test.

Across the measured setups, splitting the model into layers was faster than splitting each calculation across both cards. These findings apply to one model, one Windows Vulkan build, and one computer; they are not a universal GPU ranking.

THE RESULTS

Generation speed

Tokens per second means how many tokens the model generated each second. These ranges are medians from separate benchmark processes, not the fastest individual runs.

SetupTokens per second
RTX 3090 alone136.5–137.6

Both cards, layer split104.0–105.9
Both cards, tensor split27.9–39.1

Important: a separate wider-batch prompt test had much higher absolute speeds, though the same order: RTX alone, layer split, B70 alone, tensor split. Prompt processing and token generation are different tasks and must be compared separately.

WHAT WE LEARNED

Extra memory is not automatically extra speed.

The two cards have 32 GiB and 24 GiB of nominal memory. Together, that is not one shared 56 GiB pool. The tested 7B model fit on either card by itself, and the study did not test a model too large for one card—so a capacity benefit remains unknown.

Did the model give the same answer?

All four setups selected the same top token for 32 steps of one fixed prompt. Some detailed numeric outputs still differed at the first single-token step. A match on one prompt is useful evidence, but it does not prove general equivalence.

How much evidence?

We retained 280 timings across 20 short benchmark processes and five repetitions per measured test. No slow sample was discarded. The study did not test energy use, isolate why tensor splitting slowed down, or establish a general vendor ranking.
