CORRECTNESS BEFORE SPEED

Repeatable output.
Not identical arithmetic.

RTX, B70, layer and tensor configurations agreed on every top token for the saved 32-prefix check. The RTX reference repeated exactly; so did the full mixed tensor logit capture.

The first single-token decode has a stable numerical excess. Layer mode also shows it, despite having no tensor all-reduce. That means all-reduce is not required for the phenomenon; it does not isolate the precise cause.

Scope: one correctness prompt, one quantization and context 512. Performance uses synthetic token IDs and different effective contexts. This is not general correctness certification.

WHAT WE CAN AND CANNOT SAY

Keep the boundaries
next to the finding.

Same source, same model

Exact pin c93decc7654dac127d18fd61064565ef00bf8244. No inference-library, SDK or driver changes during the comparison. Later PR revisions are different software.

Warm decode ≠ loading

Built-in warmup precedes timings. Prompt warmup is a full prompt pass; generation warmup is one token. Model-loading-only time is unavailable for llama-bench; total process wall includes loading and delays.

All samples, not the fastest

Dots show each measured repetition; markers show process medians and ranges. Two counterbalanced blocks reveal order sensitivity but do not establish statistical significance.

Memory is observed, not pooled

Memory charts use device-wide WDDM snapshots during each process. They include all tests in that process. The 7B model fits on either card; larger-than-one-card capacity was not demonstrated.
